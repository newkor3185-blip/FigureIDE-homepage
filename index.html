Scientific figures, in one workspace

분석에서
그림 완성까지.

FigureIDE는 R 분석과 편집 가능한 벡터 그림을 한 작업 공간에 모읍니다. 그래프를 다듬고, 패널을 구성하고, 논문용 SVG와 PDF로 내보내세요.

One connected workflow

연구 그림에 필요한 도구를
한곳에 모았습니다.

R 기반 분석과 벡터 편집을 오가며 생기는 번거로움을 줄이고, 그림과 프로젝트를 함께 정리합니다.

01 / ANALYZE

R 스크립트와 콘솔

스크립트를 편집하고 실행해 결과와 R 작업 환경을 확인합니다.

02 / REFINE

연결된 그래프 편집

ggplot 그래프를 관리하고 크기와 스타일을 조정합니다. 필요할 때 R에서 다시 그릴 수 있습니다.

03 / COMPOSE

벡터 그림 구성

주석을 더하고 패널을 배치한 뒤, 편집 가능한 FigureIDE 파일과 SVG/PDF로 저장합니다.

공개 베타 · 프리릴리스

Windows · x64

FigureIDE v0.1.0-beta.1 ZIP입니다. 파일을 풀고 FigureIDE.exe를 실행하세요. R 기능을 쓰려면 R을 별도 설치해야 합니다.

macOS · Apple Silicon / Intel

현재 공개 베타 릴리스에는 macOS ZIP이 포함되어 있지 않습니다. 안정적인 다운로드 파일이 릴리스에 등록되면 이 버튼을 연결하겠습니다.

Linux · x86_64

실험용 Linux 빌드는 아직 공개 릴리스 ZIP으로 제공되지 않습니다. 공개 다운로드 파일이 준비되면 이 버튼을 연결하겠습니다.

Linux 다운로드 준비 중
R은 별도 설치 항목입니다. 벡터 편집, .fide 저장, 일반 SVG/PDF 내보내기는 R 없이도 사용할 수 있습니다. R 스크립트 실행과 연결 그래프 새로고침에는 R과 필요한 R 패키지가 필요합니다. 현재 직접 다운로드는 Windows x64 공개 베타입니다. macOS와 Linux용 ZIP은 아직 준비 중입니다.
